# Sneha Portfolio

A responsive personal portfolio for Sneha Pal, built with HTML, CSS and JavaScript. Warm ivory and sage styling, a custom cursive wordmark, animated hero and book-inspired About section.

## Local preview

```sh
python -m http.server 5173
```

Open http://localhost:5173.

## Deployment

Static website. On Vercel, choose **Other**, leave the build command empty and use the project root as the output directory. No environment variables or dependencies are required.

About is populated; Projects, Experience, Achievements, Interests, Terminal and Contact are placeholders for upcoming content. The Resume control remains disabled until a resume is supplied.
